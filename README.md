## How I like to learn

I don't really enjoy learning technology just for the sake of learning technology.

Give me a problem and I'll probably learn the technology I need to solve it.

That's why a lot of my projects are experiments:

> **"I wonder if I can make this work..."**

usually turns into:

> **"Okay, now why is it doing THAT?"**

...and eventually into something that actually works.

I'm particularly interested in understanding **why** something works instead of blindly copying a tutorial.
